# Bản thử nghiệm trình duyệt cũ

Các tệp ở đây được giữ lại từ bản HTML/CSS/JavaScript ban đầu. Dự án chính đã chuyển sang **Godot**, mở `../project.godot` để phát triển tiếp.

Có thể mở `index.html` để xem bản cũ. Luật cây lớn theo giây và bản lưu trình duyệt độc lập với bản Godot; không có chuyển đổi dữ liệu giữa hai bản.

Tệp `.gdignore` giúp Godot bỏ qua thư mục này khi import.
